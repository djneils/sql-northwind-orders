# SQL Workshop: Northwind Orders Database

A self-marking SQL activity using the classic Northwind sample database — a fictional food import/export company. Students work through 7 structured activities covering the full range of SQL skills.

## Overview

Browser-based, runs entirely client-side using SQL.js (SQLite in the browser). Open the HTML file in any modern browser and start querying.

## What's Covered

| Activity | Topics |
|----------|--------|
| 1 — Basic SELECT | `SELECT`, `WHERE`, `ORDER BY` |
| 2 — AND, OR, BETWEEN | Filtering with logical operators and ranges |
| 3 — JOINs | `JOIN` across multiple tables, `DISTINCT` |
| 4 — INSERT | Adding new records |
| 5 — UPDATE | Modifying existing data |
| 6 — DELETE | Removing records safely |
| 7 — ALTER & CREATE | Schema changes, creating new tables |

## How to Use

1. Open `northwind-orders-database.html` in any modern web browser
2. Each activity builds on the last — work through them in order
3. Type your SQL into the editor and click **Run** — results are checked automatically
4. Use the ERD (Entity Relationship Diagram) button to view the database structure

## Files

| File | Description |
|------|-------------|
| `northwind-orders-database.html` | The self-marking activity |
| `SOLUTIONS.txt` | Full solutions for all 29 questions |

## Topics / Level

**KS4 / GCSE Computing** — covers the full SQL specification from basic SELECT through to DDL
